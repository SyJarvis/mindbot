# v0.4 Runtime Mainline Closeout

## 背景

v0.4 主线已经完成三块底座：

1. `DEV-022`：`TurnEngine` 统一事件流执行入口。
2. `DEV-024`：`RuntimeSession` protocol bus 接管 TUI / HTTP stream / 普通 channel 可控入口。
3. `DEV-023`：最小 runtime request-answer 统一链路。

同时，早期 CLI/TUI 分阶段方案（`DEV-003` ~ `DEV-006`）与后续 runtime/TUI 实现发生重叠，需要明确主线边界，避免继续沿旧路线重复推进。

## 实现方案

本次只做收口，不引入 ACP 或权限/工具确认迁移：

1. 将 `USER_INPUT_REQUEST` 接入统一 `RuntimeRequest` / `on_runtime_request` resolver。
2. 保留 `on_user_input_request(question, request_id)` 兼容入口。
3. 将 `RuntimeSession` pending 状态升级为统一 runtime request pending。
4. 将 `Agent` / `TurnEngine` 直接构造默认值对齐 config schema。
5. 更新 CLI/TUI 旧 devlog 状态，明确后续以 runtime session 主线推进。
