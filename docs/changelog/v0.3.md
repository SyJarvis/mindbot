# v0.3 更新日志

## v0.3.7

- **Conversation Continuity Snapshot**：多轮对话结构化状态快照。compact()、软触发（>50% budget）、上下文丢失检测三种策略驱动更新，非每轮 LLM 调用
- 新增 `ConversationContinuitySnapshot` 数据模型（task/decisions/focus/questions/bindings）
- snapshot 作为独立 `ContextItem(source="conversation_continuity")` 参与 packer 竞争（priority=55）
- `ContextConfig.snapshot_enabled` 开关（opt-in）
- 21 个 snapshot 专项测试
